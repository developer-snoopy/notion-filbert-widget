# ☕ Coffee Brew Stopwatch

바리스타와 홈카페 유저를 위한 **핸드드립 추출 스톱워치 위젯**입니다.
단일 HTML 파일로 제작되어 노션 임베드(Embed)로 바로 사용할 수 있습니다.

---

## 1. 위젯 소개 및 개발 목적

핸드드립은 “언제, 얼마나 부었는가”가 맛을 결정합니다.
그러나 일반 스톱워치는 전체 시간만 보여주기 때문에, 추출 도중 뜸 들이기 · 1차 · 2차 구간을 손으로 계산하거나 메모해야 하는 불편이 있습니다.

**Coffee Brew Stopwatch**는 이 불편을 해결하기 위해 만들었습니다.

- 추출 중에는 **버튼 하나만** 누르면 되도록 단순화
- 구간별 소요 시간과 누적 경과 시간을 **자동 기록**
- 추출이 끝나면 그대로 **레시피 로그**로 옮겨 적을 수 있도록 구성
- 노션 페이지에 그대로 녹아드는 **커피 톤의 조용한 디자인**

> 동일한 레시피를 반복 재현하고, 맛의 차이를 시간 데이터로 설명하는 것이 목표입니다.

---

## 2. 위젯 주요 기능

### ⏱ 전체 추출 스톱워치
- 0.1초 단위의 `MM:SS.S` 형식으로 전체 경과 시간 표시
- **시작 / 일시정지 / 이어서 시작 / 초기화** 지원
- 숫자 폭이 고정된 태뷰러 숫자(tabular numerals)로 흔들림 없는 시간 표시

### 💧 3단계 추출 구간 기록
- **뜸 들이기 / 1차 추출 / 2차 추출** 버튼 제공
- 버튼을 누르면 직전 기록 이후 흘러간 **구간 시간**이 자동 계산되어 저장
- 두 번째 기록부터는 **누적 경과 시간**이 괄호로 함께 표기
- 버튼을 먼저 눌러도 타이머가 자동으로 시작되는 자동 시작(auto-start)

기록 예시

- **뜸 들이기** : 30초 대기
- **1차 추출** : 30초 대기 (1분 경과)
- **2차 추출** : 40초 대기 (1분 40초 경과)

### 🎨 커피 톤 디자인
- 아이보리 배경(`#F6EFE7`) + 연한 갈색 포인트(`#9A7654`)의 저채도 팔레트
- 기록은 제목(검은색 볼드) + 내용(회색)으로 구분해 가독성 확보
- 노션 문서 배경과 이질감 없이 어울리는 카드형 레이아웃

### 📱 가벼운 구조
- **단일 HTML 파일** (외부 라이브러리 · 빌드 도구 불필요)
- 모바일 폭(약 390px)에서는 버튼이 세로로 정렬되는 반응형 레이아웃
- 최소 44px 터치 영역과 키보드 포커스 스타일 지원

## 3. 위젯 사용 방법

### 3-1. 설치 (노션 임베드 기준)

1. `index.html` 파일을 다운로드합니다.
2. GitHub Pages, Netlify, Vercel 등에 업로드하여 공개 URL을 발급받습니다.
3. 노션 페이지에서 `/임베드` 바로 입력 → **임베드 블록** 생성
4. 발급받은 URL을 붙여넣고 “링크 임베드”를 선택합니다.
5. 블록 모서리를 드래그해 높이를 조절합니다. (권장 높이: 약 480px)

로컬에서 확인하려면 `index.html`을 브라우저로 열기만 하면 됩니다.

### 3-2. 추출 흐름

1. 물을 부기 직전 **시작** 버튼을 누릅니다.
2. 뜸 들이기가 끝나면 **뜸 들이기** 버튼을 누릅니다. → 해당 구간 시간이 기록됩니다.
3. 1차 푸어링을 마치면 **1차 추출** 버튼을 누릅니다.
4. 2차 푸어링을 마치면 **2차 추출** 버튼을 누릅니다.
5. 추출이 끝나면 **일시정지**로 시간을 멈추고 기록을 확인합니다.
6. 다음 잔을 내리기 전 **초기화**를 누르면 시간과 기록이 모두 리셋됩니다.

> 💡 기록은 브라우저 메모리에만 유지되므로, 보관이 필요한 레시피는 초기화 전에 노션 페이지에 옮겨 적어두세요.

### 3-3. 커스터마이징

단계 이름을 바꾸려면 HTML의 `data-phase` 값과 버튼 텍스트를 함께 수정합니다.

```html
<button type="button" data-phase="3차 추출">3차 추출</button>
```

색상은 `:root`의 CSS 변수만 교체하면 전체 톤이 바뀝니다.

| 변수 | 역할 | 기본값 |
| --- | --- | --- |
| `--bg` | 배경 | `#F6EFE7` |
| `--brown` | 메인 포인트 | `#9A7654` |
| `--brown-deep` | 시간 텍스트 | `#6B4F38` |
| `--muted` | 보조 텍스트 | `#8C8078` |
